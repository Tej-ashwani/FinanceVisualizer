# 💰 Personal Finance Visualizer

A simple and responsive web application to help users track and visualize personal finances efficiently.

---

## 🔧 Tech Stack

- **Frontend:** [Next.js](https://nextjs.org/), [React](https://react.dev/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Charts:** [Recharts](https://recharts.org/)
- **Database:** [MongoDB](https://www.mongodb.com/)
- **Styling:** Tailwind CSS

---

## ✨ Features

### ✅ Stage 1: Basic Transaction Tracking
- Add, Edit, Delete transactions with:
  - Amount
  - Date
  - Description
- View a complete list of transactions
- Visualize monthly expenses using a **bar chart**
- Basic form validation for user inputs
- Fully responsive with error handling

---

### ✅ Stage 2: Categories & Dashboard
- All Stage 1 features plus:
- Assign predefined categories to transactions (e.g., Food, Rent, Travel)
- View category-wise spending with a **pie chart**
- Dashboard with:
  - 💸 Total Expenses
  - 📊 Category Breakdown
  - 🧾 Most Recent Transactions
